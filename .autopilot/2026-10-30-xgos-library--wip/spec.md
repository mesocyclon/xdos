# Спецификация: DOCX и собственный PDF v1

## 1. Задача и результат
Пользователю нужна Go-библиотека генерации DOCX, редактирования любых частей, вставки документов и экспорта PDF без внешних программ. Результат — полный поддерживаемый v1 из architecture-baseline.md, включая простой API, preserving XML/OPC, merge, собственные layout/PDF и доказанную приёмку. OPC, font spike или структурная проверка этой спецификации не считаются готовой библиотекой.
Модуль и репозиторий: `github.com/mesocyclon/xdos`, локальный каталог `/var/www/xgos`. Инициализация сохраняет существующую remote-историю; отсутствие доступа к remote обозначается отдельным блокером публикации, а не готовностью репозитория.
Режим manual deep: сначала явное согласование этой спецификации, затем отдельного плана; до обоих согласований реализации нет. Этот документ не является планом тасков. Архитектурный baseline сохраняется; уточнение G03 ниже предлагается к согласованию вместе со спецификацией.

## 3. Модель данных, API и атомарность
Единственный mutable working state — private XML/OPC builder; опубликованные roots immutable. Typed handles, styles и layout — views/projections, не второй Document. XML хранит lexical spans, QName/порядок атрибутов/quotes/entities/comments/PI/whitespace/CDATA/BOM и UTF-8/UTF-16 LE/BE; encoding/xml.Marshal не является preserving serializer. Parent patch поглощает child; неизвестные QName-valued references не угадываются. Move переносит namespace/MC closure или отказывает.
Простой API шире New/AddParagraph/AddRun: text add/insert/split/delete/properties/FindRanges/ApplyEdits/Move/Clone; tables/rows/cells/grid/rectangular merges; inline images/media; sections/page geometry/first-odd-even headers-footers/link-to-previous; lists definitions/levels/instances/restart/continue; fields/bookmarks; footnotes/hyperlinks; merge/raw/history. Все используют общий edit/grammar путь, implicit point edits эквивалентны grouped Tx. Неопределённые значения отличаются от false/zero; размеры типизированы Twips/HalfPoints.
State содержит уникальные root+document+interpretation identity, не revision. Один root/options → тот же State; два candidates одного base различны; mutation/rollback/Undo/Redo создают новый envelope. CAS сохраняет candidate identity. NodeID не переиспользуется после rollback; move сохраняет, clone создаёт, delete отказывает, Undo восстанавливает. Path и Position требуют exact State, rebase отсутствует. Raw replacement уничтожает заменённые IDs.
Position offset — Unicode scalar boundary; Range полуоткрытый в одном part/story/State; marker Edge/Bias обязателен при неоднозначности. Projection хранит source map, tab/break/drawing/fields/revisions/hidden; final text исключает deleted/moveFrom/instructions. FindRanges — nonempty UTF-8 literal без regex/нормализации, gaps/fields/revisions/sdt/markers не склеиваются. AA→две непересекающиеся замены A→B даёт BB; overlapping/одинаковые вставки/вставка на endpoint замены отвергаются.
Builder+journal+seal: K append → K journal frames, не K roots. Только explicit View/Freeze/Commit seals; append не serialize/reparse/создаёт View. После seal отделяются затронутые контейнеры; random insertion может стоить O(siblings). Child failure poisons enclosing frame даже при ignored error; panic откатывается и пробрасывается. Commit проверяет delta и CAS; failure/conflict оставляет исправимый draft, success завершает; cancel после CAS возвращает успех. Rollback завершённого Tx — no-op; внешние callback side effects не транзакционны.
Snapshots/views/plans/resolvers/display живут через GC, без Close/Retain/finalizers. Caller держит immutable Source открытым для lazy reads; Close однократен, ждёт допущенные reads и возвращает прежний результат повторно. Loaded значения переживают Close, unloaded bytes возвращают ErrSourceClosed. Streams закрывает caller; facade не закрывает Source. Baseline/история могут удерживать старые backing целиком; bounded history не ограничивает чужие references.

## 4. Validation, стили и расширения
Rules = canonical edition/profile + fingerprint grammar и всех versions/config/extensions. New/Open/Store/Save/Prepare сверяют snapshot, Baseline, Origin и Validator; mismatch отвергается до FullValidate. Смена rules требует явного нового контекста/baseline, не автоматического ремонта. Strict/Transitional имеют общий semantic vocabulary; prefix/local-name угадывание запрещено.
Mutator проверяет trust boundary, owner/State, XML codepoints, limits и grammar. Commit проверяет wellformedness, OPC parts/rels/content types/internal targets и delta/index без полного typed reparse. Delete/merge требуют доказанной reference closure, raw может оставить честный DeferredReferences, unsafe OPC closure запрещена. Raw replacement parses input один раз; raw metadata может перестроить indexes линейно.
Save фиксирует один snapshot, сверяет rules, один раз выполняет FullValidate плюс integrity всех payload до первого output byte, пишет тот же root. FullValidate видит unchanged consumer→changed target. PreserveExisting допускает неизменённые legacy/unknown с diagnostics; Strict требует покрытой conformance. Security/OPC обязательны всегда; unknown не становится validated. Baseline удерживает origin для сравнения violations, не certificate; один root не сканируется дважды.
Generated grammar общая для planner/validator: sequence/choice/cardinality/wildcards/version/MC; Clear сохраняет minOccurs/inheritance; неизвестные siblings не переставляются молча. XSD ECMA-376 Strict/Transitional pin включает edition/closure/import/include/hashes/licenses/generator/toolchain/checksum; deterministic regeneration обязательна. Вне-XSD rule имеет version/нормативный пункт/fixture; Word deviations отдельно.
Resolver property-specific: docDefaults → table/numbering → paragraph → character → direct; basedOn/next/link, toggles, cnfStyle/tblLook/theme/language, provenance. Cache ограничен точным State/NodeID/context/config; не mutable свойства.
Handlers/adapters/providers immutable/concurrent-safe, per-instance и fingerprinted; duplicate/nil/ambiguous registrations запрещены. ElementHandler возвращает same Reader/Ref, recursive same-Ref отказывает. Filter = explicit Command через Apply; Save/render/read-only hooks не запускают мутацию. Error имеет Code/Location/Unwrap, Report содержит Issues/Coverage включая deferred/unknown; fatal не понижается warning.

## 5. Полный merge поддерживаемого профиля
Prepare читает target fixed Reader+exact Position и source Snapshot, строит bounded closure/mappings/preview; Plan.Apply проверяет exact target State и применяет одним frame, Commit отдельно CAS. PreserveSource сохраняет оформление; UseDestination явно меняет его с diagnostics. Reuse требует equivalence graph/context, rename относится к строкам/URI, remap к scoped IDs. Key = source document/part/kind/old ID; source не изменяется.

| Объект конфликта | Обязательное разрешение и отказ |
|---|---|
| Parts/content types/rels | URI rename + согласованный MIME; part-scoped rId remap; type/mode/target сохраняются, external не fetch |
| Styles | Graph-equivalent reuse включая basedOn/link/numbering/theme/defaults; иначе styleId rename+refs; destination mapping type-safe |
| Numbering | Equivalent abstractNum reuse, новый num instance; overrides/remap; continuation только explicit compatible levels/restart |
| Media | Reuse по bytes+type/role/graph, hash только кандидат; payload без recompression; новые drawing IDs/rels |
| Sections/headers/footers | Interval splice begin/middle/end, source final sectPr и effective first/odd/even; target prefix/suffix сохраняются |
| Bookmarks/hyperlinks/fields | Полные ranges, pair-ID remap/name rename/anchor rewrite; REF/PAGEREF/HYPERLINK parsed tokens/switches/quotes; неизвестная dependency → отказ |
| Notes/comments | Scoped IDs, definitions/separators/parts closure, целые ranges; перенос comments не обещает их PDF rendering |
| Globals/theme/settings | Target сохраняется, известные source defaults материализуются локально; нелокализуемый compat/note/field конфликт → отказ |
| Metadata/customXML/MC/unknown | Drawing IDs document-wide, paraId part-scoped, textId по edit, rsid не unique; versioned enumerator/remapper либо доказанный opaque context; иначе ErrUnknownReference |

Section final carrier принадлежит последнему interval; вставленный carrier/пустая строка/страница видны в preview. Link-to-previous сохраняется лишь при том же effective content, иначе explicit rel/empty story. При включении evenAndOddHeaders материализуются прежние target even (= odd, если режим был выключен). titlePg/header/footer независимы; source final, break policy и begin/middle/end/final проверяются fixtures. Разрез bookmark/unknown references, stale Plan или global conflict отказывают атомарно.

## 6. PDF v1 и граница точности
Runtime pure Go, без cgo/processes/browser/network/external conversion. Core docx не импортирует render/assets. Prepare владеет DOCX policy и ровно одним FullValidate target после rules check, затем semantic/compat/font/image preflight. Engine получает immutable semantic Input без Snapshot/OPC/XML/schema; Writer получает открытый immutable display и не делает layout/shaping. Стабильный layout, font embedding/subsets готовятся до первого байта; I/O/cancel после начала записи может оставить partial output.
Fonts: static TrueType glyf, RU/EN Latin/Cyrillic LTR, Regular/Bold/Italic/BoldItalic; embedded → exact configured → explicit versioned substitution → разрешённый bundled mapping. Каждый fallback имеет requested/selected/location/reason; системные heuristics запрещены. fsType/rights, fontKey/deobfuscation/coverage/corrupt checks обязательны; restricted/bitmap-only отвергаются, NoSubsetting требует разрешённый full embedding. Shaping получает paragraph context+scalar range, GSUB/GPOS/unsafe clusters; writer использует тот же FaceID и old→embedded GID mapping.
Line layout различает UAX #14, grapheme #29 и shaped clusters; tabs/indents/spacing/alignment/justify/keep/widow-orphan, soft hyphen и explicit emergency break с reshaping. Неразмещаемый grapheme/row/note/keep не clipping. PAGE/NUMPAGES/PAGEREF/notes сходятся до fixed point по breaks/values/notes distribution/geometry; oscillation/MaxPasses → ErrLayoutUnstable.

| Поддерживаемый v1 | Граница/негатив |
|---|---|
| Single-column next/odd/even sections; first/odd/even headers-footers | Continuous/multicolumn/floating wrap → отказ; headers измеряются до body |
| Fixed и approximate autofit tables, nesting/rectangular spans/merges/repeated headings | Min/preferred dxa/pct/auto/tblW/tcW/grid/spans/padding; bounded deterministic deficits/rounding/reflow; impossible minima/сложный split-vMerge → отказ |
| Approximate autofit по умолчанию, включая default tblLayout | Warning part/node/width/assumptions; ExactGeometry запрещает; никаких shrinking/clipping/mutation DOCX |
| Simple footnotes, PAGE/NUMPAGES/PAGEREF, hyperlinks/bookmarks | Note separator/continuation/multipage; endnotes/full TOC/other fields → отказ либо explicit CachedResult warning |
| PNG8/JPEG8, Gray/RGB, alpha/clipping, extents | PNG16/CMYK/YCCK/EXIF rotation/unknown ICC → отказ; pixel limit до decode; writer принимает validated samples/JPEG, не PNG |
| Final revisions projection, sdtContent, supported MC fallback | Warning revisions; no databinding; unknown visible/OMML/charts/SmartArt/comments → отказ |
| PDF 1.7, exact Unicode extraction, links/destinations | ToUnicode/ActualText many-to-many; tagged/PDF-A/encryption/signatures вне v1; свой parser не oracle |

Compat `xgos-v1` учитывает name/uri/value/default; unknown → UnsupportedCompatibility, лишь отдельный AllowCompatibilityApproximation разрешает базовую семантику. Autofit permission его не заменяет. VisiblePlaceholder opt-in с warning и отдельным статусом, не normal success.

### 6.1. Предлагаемое уточнение baseline §8: нумерация всех stories (G03)
Нумерованные списки входят в main body (включая table paragraphs), обычные/first/even headers и footers, простые footnotes. Поддерживаются num/abstractNum/levels/overrides/start/restart/lvlText, decimal/decimalZero/Roman 1..3999/Latin letters/bullet/none; picture bullets/иные formats → refusal.
Prepare один раз строит paragraph→label map по (logical numbering scope, numId), включая вложенные таблицы. Логические scopes: main body; общая группа headers+footers; общая группа footnotes. Physical part/note definition не создаёт новый counter автоматически: header и footer продолжают общий счётчик, обычные note definitions продолжают общий footnotes counter; body независим. Нумерация самих сносок и separator/continuation не смешиваются со списками внутри сноски.
Каждый distinct header/footer part обходится один раз: sections в document order, внутри section first/default/even header, затем first/default/even footer, только впервые встретившийся effective part; внутри part XML-order. Footnote definitions обходятся в порядке первого body anchor, внутри note XML-order. Повторное placement inherited/reused part на pages/sections лишь повторяет готовые labels; multipage note и pagination passes не продвигают counters. Это детерминированный v1 порядок; Word-эквивалентность требует квалификации.
Explicit restart/continue работает внутри совместимого logical scope/num instance, включая разные physical parts общей группы. Continuation между body/header-footer/footnotes scopes не поддерживается: explicit запрос отвергается; одинаковый numId scopes не объединяет. Исследованный pinned docx4j NumberingStoriesTest подтверждает upstream ожидания shared header-footer и shared notes, но не является Word oracle. Stage 0 обязан сверить эти assertions, порядок first/even/inherited parts и повторные placements с независимым Word output; отсутствие доказательства оставляет G03 acceptance открытым, не исключает поддержку. При расхождении меняется versioned technical contract до freeze, без молчаливого угадывания.
Fixtures: body+tables, normal/first/even header/footer, inherited/reused parts через sections, shared footnote counters при независимости body, multipage notes, overrides/restart, второй layout pass, unsupported formats и explicit cross-story refusal; expected labels независимы от production counter implementation.

## 7. Стоимость операций и архитектурные правила
N = bytes/nodes документа, Δ = изменённая область, C = dependency closure, V = visible content, K = команды; «retained» включает unique roots/backings caller/history/cache. Limits конечны: zero defaults, negative/overflow/incompatible error, allocation проверяется заранее. Memory = input + operation work + retained, не глобальный RSS cap.

| Операция/область | Reads и copies | Retained | Limit | Доказательство |
|---|---|---|---|---|
| Open / first XML parse | ZIP metadata; lazy payload; first parse O(bytes+nodes), копия inflated backing | Parts/index + разобранные backings | Parts/expanded bytes/ratio/depth/tokens/workers | Empty/hostile/lazy corpus; cold/warm bytes и heap |
| Local grouped append | O(detached containers + added bytes/nodes + K journal); без K root copies/reparse | Новые nodes/journal, shared old roots | Visited/copied/text/history | Public 1k/2k/5k/10k bulk ratios; инструментированный no-seal path |
| Random/raw edits, View | O(siblings) или O(raw input); explicit View вызывает seal и будущий detach | Old/new snapshots/backings | Edit work/copied bytes | Local vs whole input; View-heavy отдельно, rollback retention |
| Commit | Seal+dirty checks/index delta; raw metadata допускает O(parts+rels) rebuild | Candidate/publication/history | Delta/index/history budget | Typed append не full scan; two-candidate CAS/alloc profiles |
| Query/FindRanges/style | Visited scope/text, поиск source map; cached effective по exact context | Fixed view + bounded cache | Query/text/cache | Long runs/filtered gaps/cache invalidation; output allocs |
| Merge | O(source closure + target indexes/scans + splice/materialization); cold target styles/IDs/global checks могут читать все target parts; media reuse только доказанный | Source/target roots+Plan closure | Closure/parts/bytes/visited | Small insert в large target, shared media/unknown cycles/cancel |
| Save (whole document) | Full validation/integrity N + output bytes; no hidden second mutable DOM | Fixed root + bounded ZIP scratch | Expanded/output/work | Unchanged consumer→changed target; validation count=1; streaming high-water |
| Prepare/layout (whole visible document) | Validation N, semantics/counters V один раз; shaping и bounded passes | Input/resources/display/fonts/spool | Glyphs/pixels/scalars/cells/depth/width-passes/pages/passes/spool | Notes/fields/autofit convergence; font/image-heavy CPU/heap |
| Writer/display traversal | O(commands+glyphs+resources), subset before output; traversal без IR deep copy | Display + subset/resource tables | Glyphs/fonts/output/work | Two-pass traversal alloc threshold; independent PDF parser/extraction |
| Undo/Redo/source/cache | Journal/root references; не clone всего документа | Unique retained bytes; eviction снимает свои refs | History/cache; caller refs отдельно | Old snapshots+Close race+GC heap slopes, concurrency baseline |

Независимые parts: errgroup.WithContext/SetLimit/Wait, общий finite budget без nested blocking submission; failure cancel siblings, join до возврата; scheduler не меняет IDs/order. sync.Pool только scratch, oversized buffers не возвращаются; published backing не pooled. Отмена проверяется в bounded loops; disk spill нет; blocked ReaderAt/Writer требует caller timeout.
Каждый пакет имеет одного владельца данных/инвариантов по interfaces.md. Split/merge требует краткого обоснования cohesion: какие инварианты/данные общие, какие callers/imports изменятся; пустые обёртки и util/manager dumping ground запрещены. Import check проверяет direct DAG и core closure. Не добавлять abstractions ради гипотетических нужд.
Перед bugfix проследить все callers до публичных границ, назвать shared owner причины, исправить один инвариант и добавить regression там, где пользователь видит дефект. Review фиксирует impact на consumers/tests/fixtures/config/exports и объясняет каждый выход за подсистему; duplicated validation, private workaround и несвязанный churn не принимаются.

## 8. Корпус, метрики и доказательства
Публичный поиск оформляется в `research/corpus-report.md` и `research/manifest.json`: seeds структурных fixtures отдельно от независимых DOCX→Word PDF/image oracles. Для qualification обязательны URL/revision/path/SHA-256/license/provenance/features/profile/rules/fonts/rights/Unicode/mapping/policies/limits/toolchain, Word/version/export environment у независимого output. Несовпадающие/недоступные fonts запрещают exact geometry claim; наличие PDF само по себе не квалификация.
Сохранён seed: 16 DOCX + 11 PDF. 10 synthetic DOCX/Word PDF pairs из docxide-pdf @c2fa4fa461d987653dc717d7327096e57afb4686 (README Word Mac 16.106.1+, Creator Microsoft Word, generator/export provenance); 5 structural python-docx fixtures @e45454602b53e8e572b179ccf1c91093ec9f4ed7; 1 реальная авторская документация docx4j @4cc16a7c70f4ee7499260ae8bdeed0f7ac7e133b и её FOP PDF comparator, не Word oracle. Apache POI — metadata-only кандидат. Pins/licenses/hashes и источники закреплены в research/manifest.json и corpus-report.md. Qualified exact Word geometry = 0: private upstream fonts не закреплены, independent parser/raster отсутствуют; ни один library PASS не получен. RU/EN mixed/combining, lists/tables/spans/images/sections/notes/fields и hostile/unsupported/fonts/limits должны иметь positive/negative coverage; пробелы закрываются до release.

| Метрика H0 | Gate и учёт |
|---|---|
| Critical/regression и expected refusal | 100% заявленных checks; у refusals отдельно code+location; denominator не уменьшают |
| Content/warnings | 0 missing Unicode spans/visible objects/glyphs, 0 unexpected warnings; независимый extraction/source mapping |
| Exploratory positive | ≥95% заранее positive проходят профиль, не только nil error; critical не подменяется процентом |
| Exact geometry | Δpages=0, p95 matched bbox error ≤1 pt, unmatched content=0, exact fonts/policies |
| Approximate geometry | ≥90% Δpages=0; остальные abs(Δpages)≤max(1,ceil(0.05×referencePages)); location warnings |
| Lines/visual | Matched line-break mismatch/unmatched lines/pixels при fixed DPI; thresholds фиксирует Stage 0 ADR, без independent renderer visual gate открыт |
| Bulk/no-copy | T(2N)/T(N)≤3 и AllocBytes ratio≤3 для 1000→2000 и 5000→10000; второй display traversal ≤1% glyph payload allocated bytes, scalar checksum |
| Resources | Wall/CPU p50/p95, allocs/op/bytes, peak RSS/heap, baseline/concurrency/retained roots/font/image/spool high-water; pinned hardware/toolchain/GOMAXPROCS |

H0 не измерения: Stage 0 может изменить гипотезы только versioned ADR до freeze acceptance manifest, после результатов переклассификация/подгонка запрещена. Goldens независимы от planner/writer; обязательны roundtrip bytes+semantics, GSUB/GPOS/clusters/GID/checksum/rights, geometry/Unicode/visual, race/fuzz и public benchmarks. Каждый найденный bug получает regression fixture. Структурная самопроверка документов не runtime/golden/benchmark acceptance.

## 9. Решения, открытые gates и вне рамок
Границы, владельцы, signatures, прямой DAG и test seams: [interfaces.md](interfaces.md). Решения: spans ради preservation; GC+caller Source ради простого lifetime; journal/seal ради bulk; exact State ради stale/CAS; fast Commit/full output ради стоимости; scoped merge ради ссылок; Prepare→Input→display ради замены engine/writer; render-only bundle ради core isolation.
Go 1.23 — минимальный язык из baseline (`iter`); наличие host Go 1.27.3 не доказывает поддержку 1.23. До release нужен CI minimum/current на pinned dependencies, CGO_ENABLED=0 и контроль отсутствия внешнего runtime. Новые Docker environments/volumes не создаются; существующее окружение/host tools используются по AGENTS.md.
Stage 0 технические placeholders: квалифицировать и закрепить shaper/subsetter (go-text/typesetting v0.3.5 только кандидат), font bundle (Carlito/Liberation только кандидаты), XSD source/generation, независимые extraction/render tools и corpus rights/fonts, численные visual thresholds. Для каждого нужен version/hash/license/evidence/ADR; отсутствие инструмента/rights не заменяется self-oracle. Spike проверяет shaping→manual display→PDF→independent extraction и subset отдельно; dependency/tool installs до согласования плана не разрешены этой спецификацией.
Главные риски: fidelity и compat, autofit convergence, font embedding/extraction, cross-part merge closure, retained memory и grammar coverage. Невозможность доказать перенос/геометрию даёт точный отказ; пересмотр заявленного v1 требует пользователя, не скрытого сужения acceptance.
Вне v1: полный typed OOXML/Word layout, templates/automatic rebase/full XPath, revision accept/reject, произвольные OMML/charts/SmartArt, все scripts/fonts/Bidi/CFF/variable/color, encrypted DOCX, PDF/A/tagging/signatures/encryption, network/processes/cgo/disk spill. Неподдерживаемый XML сохраняется в пределах security/preservation policy; signed edit требует explicit RemoveOnEdit с атомарным удалением подписей/rels и warning.
Ничего из реализации/runtime/corpus fidelity/performance этой спецификацией не заявляется выполненным. Новых A-capabilities нет; требования не сняты и не отложены за v1.
